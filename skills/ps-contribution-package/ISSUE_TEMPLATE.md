# Local Issue Draft Template

Use this only as local markdown for a human to post manually.

## Numbered slice summary

Start the issue pack with a numbered list:

1. **Title**
2. **Type**: AFK or HITL
3. **Blocked by**
4. **Why this slice exists**

## Issue draft

```md
## What to build

Describe the end-to-end slice in maintainer language. Explain the behavior and the integration boundary, not only the code change.

## Why this is the smallest useful slice

Explain why this can stand alone and why it does not require broader repo churn.

## Acceptance criteria

- [ ] Criterion 1
- [ ] Criterion 2
- [ ] Criterion 3

## Blocked by

- None - can start immediately
```
